# Leaderboard-Bot
Discord bot for users to create leaderboards for any reason.

Functions/Commands for bot:
- Add game leaderboard (i.e. Monopoly)
- Add player to game leaderboard (i.e. add Ryan to Monopoly)
- Add a win to a game for a specific player (i.e. add 1 point to Jose for Monopoly)
  - Allow for partial points (i.e. 0.67)
- Remove a win from a game for a specific player (i.e. minus 1 point from Ryan for Monopoly)
- Show ranking for a specific game for a specific person
- Show leaderboard for a specific game (i.e. top 3 or show whole leaderboard)
- Remove a player from leaderboard (i.e. remove Carrots from Monopoly)

Additional Features:
- Set a score for a specific player on a specific game
- Reset a players score to 0 (add confirmation)
- Remove the leaderboard entirely (add confirmation)
- Reset a leaderboard all to 0 (add confirmation)
